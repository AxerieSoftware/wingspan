Wingspan keeps its items, due days and settings in the notes of one manual account named "wingspan". It creates that account, hides it from Monarch's lists and leaves it out of net worth, so every browser and everyone in the household sees the same data. Wingspan's page in Monarch's Settings links to it.

<Screenshot name="where-wingspan-saves" alt="Wingspan's settings page in Monarch, explaining where it saves, with a link to the wingspan account." />

The notes start with a line asking people not to edit them. If an edit leaves them unreadable, Wingspan says so and doesn't save over them. Outside that account, Wingspan writes to Monarch only when you ask: the receipts you send with retail receipt sync, and a manual loan's balance when you save one with [Update balance](/features/interest-cost/#keeping-a-manual-loan-current). It never changes any other account, even one with the same name.

## Saved in the browser instead

A few choices only change how Monarch looks to you, so each browser keeps its own:

- [Workspaces](/features/workspaces/): which workspace you're in, and whether workspaces are on.
- [Sidebar items](/features/sidebar-items/): which items are hidden from the sidebar.

Each feature's page says where it saves, under its title.

## The copy in the browser

The browser keeps a copy for a fast start and for when Monarch can't be reached. A change that can't reach Monarch waits there and saves once Monarch is back. Each Monarch household that signs in to the browser gets its own copy, so households never mix.
