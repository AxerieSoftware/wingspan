title: Where Wingspan saves
description: In your Monarch account, so the household shares it.
---

Wingspan keeps its items, due days and settings in the notes of one manual account named "wingspan". It creates that account, hides it from Monarch's lists and leaves it out of net worth, so every browser and everyone in the household sees the same data. Wingspan's page in Monarch's Settings links to it.

<Screenshot name="where-wingspan-saves" alt="Wingspan's settings page in Monarch, explaining where it saves, with a link to the wingspan account." />

The notes start with a line asking people not to edit them. If an edit leaves them unreadable, Wingspan says so and doesn't save over them. Apart from that account, the only thing Wingspan writes to Monarch is the receipts you send with retail receipt sync, and it never touches any other account, even one with the same name.

The browser keeps a copy for a fast start and for when Monarch can't be reached. If a change can't be saved to Monarch, it's kept there and saved once Monarch is reachable again. Each Monarch household that signs in to the browser gets its own copy, so households never mix.
