Wingspan adds what Monarch doesn't do yet, on the Monarch pages you already use. Each feature's page shows how it fits your Monarch routine.

<FeatureMap />

Everything Wingspan adds carries a small Wingspan mark. If Monarch has a similar feature planned, Wingspan uses Monarch's name for it, and removes its own version once Monarch releases it. Wingspan never unlocks Monarch's paid features.
