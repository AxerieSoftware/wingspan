Wingspan adds what Monarch doesn't do yet, on the Monarch pages you already use. Each feature below has its own page with how it fits your routine in Monarch.

<FeatureMap />

Everything Wingspan adds carries a small Wingspan mark, so you can tell it apart from Monarch's own. If Monarch has a similar feature planned, Wingspan uses Monarch's name for it. When Monarch releases it, Wingspan's version is deprecated and removed. Wingspan never unlocks Monarch's paid features.
